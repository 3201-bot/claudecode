# 検品ゲートと利益計算

リサーチで出た候補は、**全件このゲートを通過するまで下書きにしない**。ゲートの通過率が低いのは正常(現場の実測で、候補の9割が却下される日もある。それが正常値)。

## ゲート⓪(入場前チェック): 重複の除外

6段のゲートに入れる前に、候補が**すでに手元にないか**を確認する:

- 仕入元URLが台帳のS列に既出 → 除外(ステータスが「取下げ」「売れた」なら再出品の可否をユーザーに確認)
- 同一SKU・同一型番+同一状態の下書きがe-STOCKERに既存 → 除外
- 却下記録に同一候補がある → 再提案しない

3軸リサーチは同じ商品に別ルートで到達する。このチェックを飛ばすと同一商品の重複出品(eBayポリシー違反)につながる。却下する場合も理由「重複」で記録する。

## 検品ゲート(1件ずつ実ページを開いて確認)

1. **生存確認**: 仕入元ページを開き、販売中であること。売切れ・取引中は即除外
2. **実価格確認**: 表示されている実価格をSKUのM値に採用。想定価格・過去価格は使わない(実測: AI見積もり22件を後日全件照合したら22件全部が実勢より甘かった)
3. **状態読解**: タイトルだけでなく**説明文の全文と状態欄**を読む。「ジャンク」「動作未確認」「電池切れ」「部品取り」「本体は付属しません」を検出:
   - 良品として出すのは禁止
   - ただし「出さない」ではなく、**ジャンク・訳あり品として明記して出す**選択肢を提示する(For parts or not workingという公式区分がある)。禁止は無申告と過大表記のみ
4. **同一性確認**: 型番・色・付属品(箱/説明書)・世代を写真と説明文で照合。除外ワード(research.md参照)に該当しないか
5. **高額品判定**: ユーザー設定の金額以上、または真贋リスク品(PSA/ブランド/貴金属)→ 自動化せず要検討リストへ
6. **利益計算**(下記)を通過したものだけが下書きへ進む

却下した候補も「却下理由つき」で記録する。却下記録は市場観の資産になる。

## 利益計算 — 手数料をヘルプページで信じない

計算式(販売価格から引くもの):

1. **eBay手数料**: ヘルプ記載の率で計算すると実際より約3ポイント甘くなる。理由は実測で2つ判明している:
   - FVF(落札手数料)の基数は商品価格ではなく**米国売上税込みの注文合計**(実測 **×1.0775**)
   - eBayは日本セラーの**手数料全額に消費税10%を課す**
   - 実測値: 売値$330の案件で手数料は**17.44%**だった(FVF13.25% + 国際1.35% + 固定$0.40、これに消費税10%)

2. **⚠️ 関税は「送料」と「変動費」のどちらか一方にだけ入れる — 最頻の事故がこの二重計上**

   米国向けは Section 301 の**12.5%**が乗る(2025年10月17日からeBayが日本発・米国宛にDDPを必須化。回避不可)。
   問題は、**この関税がどこに現れるか**が見積の出し方で変わること:

   | 送料の取り方 | 関税はどこにあるか |
   |---|---|
   | **CPaSS / SpeedPAK / FedEx / DHL の見積** | **送料に含まれている**(DDP前払い) |
   | **日本郵便(EMS等)の料金表** | 含まれていない(純粋な運賃だけ) |

   実例: SpeedPAK Economy の見積 ¥9,930 の内訳は
   運送料金¥2,660 / 燃料割増¥319 / 輸入通関手数料¥245 / 関税処理手数料¥138 /
   **推定関税及び税金料金 ¥6,568**。最後の1行が売値のちょうど12.5%。

   **だから次の2通りのどちらかに揃える。混ぜると必ず外す:**

   - **A: クーリエ見積を使う場合** → 変動費に関税を入れない。
     `利益 = 売値 × 0.784 − 見積送料(関税込み) − 仕入 − 梱包`
     係数 0.784 = 1−[(13.25%+1.35%)×1.0775×1.1 + 広告2.1%×1.1 + 為替2%]

   - **B: 郵便の料金表を使う場合** → 変動費に関税を入れる。
     `利益 = 売値 × 0.659 − 運賃(関税なし) − 仕入 − 梱包`
     係数 0.659 = A の係数 − 関税12.5%

   係数は**広告率2.1%(このスキルのデフォルト)**で導出している。広告率を変えたら係数も引き直す
   (0.1%上げるごとに係数は約0.0011下がる。例: 広告2.5%ならA=0.779)。FVFがカテゴリで違う場合も同様

   **「変動費34〜35%」という丸めた数字を使うなら、それはBの側(関税込み)。**
   Aの見積と一緒に使うと**関税を2回引く**ことになり、実際は黒字の案件を赤字と判定する。

   **実測による検算**(売値$330・米国・仕入¥28,000・CPaSS送料¥9,930):

   | 計算 | 結果 |
   |---|---:|
   | 実際(手数料明細と送料内訳の実測) | **+¥5,370** |
   | 変動費34.5% + CPaSS送料(=二重計上) | **−¥3,599** |
   | 差 | **¥8,970** |

   ※検算の前提: レート159.29円/$、売値$330=¥52,566、手数料実測$57.54、旧式の34.5%は売値比。
   なお式Aでこの取引を計算すると+¥3,182になる(表示どおり係数0.784で計算)。実測+¥5,370より低いのは、この取引では
   広告費が発生しなかったため。**式Aは広告費込みの保守的な見積**であり、この差は安全側。

   **却下が続く・自分の手計算と食い違う場合は、まずここを疑う。**

3. **仕向地で係数が変わる — 計算の前に必ず届け先の国を確認する**

   世界は2型に分かれる。**米国型**(Section 301関税あり・手数料の基数に売上税が乗る)と**それ以外**:

   | 仕向地 | 係数(広告2.1%時) | 根拠 |
   |---|---|---|
   | 米国 | **A 0.784 / B 0.659** | 301関税12.5%・手数料基数×1.0775(実測) |
   | 英国 | **0.796** | 301なし・基数=売値。£135超のVATは買い手が税関で払う |
   | 台湾 | **0.796** | 301なし・基数=売値(実測済・EMS 1kg ¥2,200) |
   | その他 | 英国式 0.796 を初期値に | 301は米国のみの措置。**初出荷の実ラベルで必ず校正** |

   実感の目安: 同じ$300の成約で、米国宛と英国宛では手取りが**約¥6,500**違う($1,000なら約¥22,000)。
   オファーの受諾判断を米国前提でやると、それ以外の国の買い手に安売りする。

   **関税12.5%の中身(Bの側で使う値)**: 2026-07-24発動の米301条関税により、日本からの輸入は
   **総関税率 = max(品目の通常税率, 12.5%)**。通常税率が12.5%未満の品目は12.5%へ引き上げ
   (例: ゲーム機 実測10%→12.5%、書籍・雑誌 0%→12.5%)、12.5%以上は据え置き(例: 時計15%)。
   自動車・鉄鋼など232条対象等の除外品目あり。台帳の関税%列はこの前提で置き、
   **実ラベル・入金明細の実測が出たら必ず実測値へ置き換える**。関税制度は動く——
   新カテゴリの初出荷時と月1回、「米国向け関税の最新状況を確認して」で裏を取ってから利益計算に使う。

4. **送料**: 仮定で置かない。同カテゴリの過去の実測があればそれを使う(実測ではカテゴリ間で¥1,700〜9,000と6倍の差があった)。実測がなければ配送会社の料金表から重量帯で引き、初出荷後に実測値へ差し替える
   - **見積の内訳を必ず開く**。総額だけ見ると上の二重計上に気づけない
   - **クーリエは容積重量で課金する**(郵便は実重量のみ)。実測例: 同じ1.07kgの荷物で箱の高さを50cm→5cmにしたら見積が**¥8,397→¥2,592**になった
   - **内容品総額20万円超**の郵便は、輸出申告の**通関代行費が別途かかる**(日本郵便で¥2,800)。クーリエは自社通関なので不要
   - **高額品の"見えない費用"は利益計算とBO自動拒否ラインの両方に最初から織り込む**:
     20万円超の通関代行費・EMSの損害要償額の保険料(¥2万超は2万円ごとに+¥50。例: ¥20万の商品でも**追加¥450**で全額カバー)。
     高額品ほど「売れたのに思ったより残らない」が起きる。売れてから気づく費用をゼロにする

5. **配送方法は「紛失時にいくら戻るか」で選ぶ**

   運送各社の補償は料金と比例しない。追加補償を掛けない場合の基本の責任限度額は、
   航空運送では**国際条約(モントリオール条約)または各社約款**により低く抑えられている。
   Orange Connex公式規約+各社約款で確認した実額:

   | サービス | 補償上限(追加補償の有無を含む) |
   |---|---|
   | EMS(日本郵便) | 損害要償額まで(**追加料金で設定する方式**: ¥2万まで無料、超過は2万円ごとに+¥50、**最大¥200万**) |
   | SpeedPAK Economy | 市場価格まで。**ただし商品価値の上限が 米国$1,200 / 英国£135**(超えるとサービス対象外) |
   | SpeedPAK DHL | 市場価値 or **26SDR/kg(約$35/kg)** の低い方 |
   | SpeedPAK FedEx | 1配送$100 or $20/kg の高い方 |

   **重要な注意**: 運送会社との直接契約では、DHLは**Shipment Value Protection(保険)**、
   FedExは**従価料金による運送責任限度額の引上げ**(declared value・保険ではない)を利用できる。
   基本の限度額が低いのは「上乗せは別料金」という設計のため。
   **ただしCPaSS/SpeedPAK経由では、これらを掛ける手段が画面上確認できていない**(2026-08時点の実測)。

   → **原則(CPaSS経由の場合): 商品価格$200以上ではEconomyを使わない。いくら安くても。**
   **高額品は、金額を指定して補償を掛けられることが実測で確認済みのEMS+損害要償額を使う。**
   数千円の送料差は、紛失時の全損(仕入+逸失利益)と比べれば保険料として安い

6. **初売上が立ったら必ず校正する**: 実際の入金明細(取引の詳細→手数料の詳細)と配送業者の送料内訳を突き合わせ、係数を実測値に差し替える。式を直したら**計算済みの全候補を再計算する**
7. **仕入価格**: SKUのM値(実ページ確認済みのもの)

判定:
- **利益率は目安、利益額が本体**。「率20%以上」を機械的に適用しない。高額品は率15%でも利益額が大きければユーザーに提示する。低単価は率が良くても作業負けするなら見送る
- 判定に迷う場合は、判定理由と選択肢を添えてユーザーに提示する

## 価格設計とシッピングポリシー

- 基本は**送料込み(FREE)**に寄せる。関税相当分・送料は商品価格に織り込む
- シッピングポリシー名は「FREE-DDP-1KG」のように**名前だけで中身(送料/関税/重量帯)がわかる命名**にする
- 送料を別建てにする商品群で関税相当分を送料に織り込む場合、**eBayの自動同梱割引がその織り込みを壊す**。同梱値引きは自動設定を使わず手動インボイスのみ
- ポリシーを量産・修正したら、**別セッションの読み取り検品**で期待値表と突き合わせる(人間の手作業ミスの実例: 説明文は直したのに価格欄が旧値のまま、米国欄と国際欄が逆)

## 出品価格の初期値

- ベンチマーク(同等品のSold)の**0.95倍**を初期値の目安にする(Soldがない場合はアクティブ最安の5%下、ただし「売れていない価格」であることをユーザーに明示)
- ベンチマークから取ってよいのは価格と需要だけ。タイトル・状態・説明は自分の実物から
